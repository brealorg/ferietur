# Store assets — neste visuelle steg

Ikke bruk AI-mockups av appen i Store listing.

Før Closed/Production trenger vi en egen STOREASSET01-runde med:

- 512×512 Play Store-ikon eksportert fra canonical Ferietur-vectoren;
- 1024×500 feature graphic i Ferietur-identiteten;
- ekte screenshots fra kvalifisert app på Pixel, ikke genererte UI-bilder;
- minimum to relevante phone screenshots; helst en ryddig serie som viser startside, turplan, beregningsgrunnlag og PDF/oversikt.

Store-asset-runden skal ikke endre appens produktkode.
