# A55R4 — Step 2 Oslo visual polish

A55R4 preserves the A55R3 form structure and changes presentation only.

## Visual changes
- selected salary model uses Oslo yellow (`colorScheme.secondary`)
- subtle yellow selected-row tint
- section headings reduced to a calmer Material hierarchy
- selection group uses the medium shape instead of the large card shape
- dropdowns are rendered as field-like surfaces rather than pill buttons
- locked normal-turnus employer field shows a compact `Fast` affordance
- rules become a compact outlined row with an Oslo-yellow info treatment
- supporting copy is shortened without changing semantics
- vertical spacing is reduced

## Invariants
No production domain, tariff, persistence, PDF, payment, employer, or flow semantics are modified.

The known `Steg 2 av 8` / `Steg 2 av 9` flow-count inconsistency is outside this visual slice.
